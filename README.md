# 🏋️ Fitness Trainer App

> Aplicación de entrenamiento físico con rutinas personalizadas y seguimiento de progreso.

## 📋 Descripción

**Fitness Trainer App** permite a los usuarios:

- 🏃 Crear rutinas de entrenamiento personalizadas
- 📊 Registrar series, repeticiones y peso
- 📈 Visualizar progreso con gráficos
- ⏱️ Cronometrar descansos entre series
- 🎯 Establecer objetivos semanales
- 📱 Funcionar offline (PWA)

## 🛠️ Tecnologías

- **Backend**: Node.js + Express
- **Base de datos**: PostgreSQL / MongoDB
- **Testing**: Jest
- **CI/CD**: GitHub Actions

## ⚙️ Requisitos

- Node.js >= 20
- npm >= 10
